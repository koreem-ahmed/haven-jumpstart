# haven-jumpstart

## Description:
It is a very simple platformer game with basics controls and a beautiful pixel art. i made the level based on mario it is a simple platformer but with a moving platform and a stair like platform. also i added some good animations and effects.

## Story
This game is about a dark knight that lost his soul to a witch which is hiding inside a cave. The knight is searching for the entrance and at the end of the game he will find the entrance.
